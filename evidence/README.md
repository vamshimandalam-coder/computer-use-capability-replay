# Evidence

Evidence in this directory is generated by the documented commands, never hand-authored. `discovery/` contains the genuine OpenAI-driven browser run, including recorded-step IDs, and `artifacts/` contains the parameterized capability constructed from those executed steps. `replay-success/` is a plain deterministic replay; `replay-recovery/` records the one-attempt known-interstitial recovery with a different valid member; `replay-exception/` demonstrates `MEMBER_NOT_FOUND`; `replay-failure/` contains a precisely classified permission failure, intervention request, and screenshot; and `handoff/` shows that failure transferring the same live replay session to a human operator and resuming with outputs. Logs redact synthetic member identifiers and omit prompts, cookies, credentials, and hidden reasoning. Replay logs explicitly report zero model initialization and zero calls.

`video/computer-use-demo-narrated.webm` is the narrated and captioned overview recorded from the real local UI. Regenerate the silent source with `npm run record:video` while the target application is running, then add the local Windows narration with `npm run narrate:video`.
